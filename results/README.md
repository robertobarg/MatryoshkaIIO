# Directory of computational results

This directory includes the complete results of the numerical experiments over all problem instances and distance functions, reported instance by instance.
All experiments were conducted on a PC equipped with a 12th Gen Intel Core i9-12900 CPU @ 3.8GHz, 32GB of RAM, and running Ubuntu 22.04 LTS.

Distance function ID

* `OF1`: Euclidean
* `OF2`: Squared Euclidean
* `OF3`: 1-norm
* `OF4`: infinity-norm


List of files

* [csv](./bonneel_ns.csv), Bonneel's Network Simplex results
* [csv](./iio4dtmrk.csv), IIO for DOTmark results
* [csv](./matrywiio4dtmrk.csv), Matryoshka with IIO for DOTmark
